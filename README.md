# Pomodoro Timer

A simple Pomodoro timer built with HTML, CSS, and JavaScript, to help you stay focused and track your study or work time.

**Live demo:** https://rose12wail-cpu.github.io/timer/

## Features

- Three modes: Focus (25 min), Short Break (5 min), Long Break (15 min)
- Automatic switching between modes, with a long break after every 4 focus sessions
- Start, pause, and reset controls
- Sound alert when a session ends
- Time shown in the browser tab title
- Space bar shortcut to start and pause
- Daily and weekly stats with a 7-day bar chart, saved in the browser using localStorage

## Technologies

- HTML
- CSS
- JavaScript (no libraries)

## How to run locally

1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension, or just double-click it.

## Project structure

- `index.html`: page structure
- `style.css`: styling and mode colors
- `script.js`: timer logic, modes, and stats
